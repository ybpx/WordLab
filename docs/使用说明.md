# WordLab 使用说明

## 零、怎么打开

双击项目目录里的 **`启动WordLab.bat`**，等浏览器自己弹出就是网站了（地址是 http://localhost:4173 ）。

- 第一次双击会多花一两分钟装依赖、构建版本，之后再双击几秒就开。
- 那个黑色命令行窗口就是网站本体，**用的时候别关**；关掉网站就停了，数据不会丢。
- 电脑需要装 **Node.js 20.19 以上（20.x 要 ≥ 20.19.0）或 22.12 以上**（https://nodejs.org/ 下 LTS 版）。版本不对时双击会直接告诉你当前版本、要求多少、去哪儿下载。
- 只有这台电脑能访问，别人打不开。查词的英文例句和翻译要联网，不联网只影响这部分，音标和中文释义是离线的。

## 一、这是什么

WordLab 是一个给高中生用的英语单词记录网站。你在做题、上课、读书时遇到生词，打开它，输入单词，它会自动查好音标、词性和中文释义，你补上遇到的例句，点保存——这个词就留在了你自己的单词本里。

数据存两份：
1. 浏览器里（IndexedDB），页面读写靠它；
2. 电脑上的 WordLab 数据文件夹里（一个 JSON 快照），每次改动都会自动更新。

## 二、三个页面

### 1. 记录单词

1. 顶部选「学习来源」（阅读 / 听力 / 写作 / 考试原句…）。来源用来以后统计"这个词我是在哪遇到的"，第一次用可以先不管。点「+ 新增来源」可以直接加一个，**点输入框外面或者按 Esc 就取消，不会存进去**。
2. 在输入框里打单词，按回车或点「查询」。
3. 页面立刻显示查询进度：
   - 本地词典：查询中 / 已完成（命中几条释义）
   - 在线词典：查询中 / 已完成（英文释义、例句）
   - 例句翻译：查询中 / 已完成
   - 右边一直跳「已用时间 3.2 秒」

   哪个来源失败，就只影响那一项，并明确告诉你原因（比如"在线词典请求超时"），不会一直转圈。查得慢不等于失败，稍等一下或者点「重新查询」。
4. 查完自动填好音标（英式/美式）、词性+中文释义、例句（附机器翻译），全都可以逐条改。
5. 遇到好句子，点「添加考试原句」或「添加例句」，把原句和中文抄进去。
6. 点「保存并录入下一个」。保存成功后输入框自动清空，可以直接录下一个词。

**草稿不会丢**：你查了词、改了内容但还没保存时，切到「我的单词本」或「设置」再回来，内容都还在；刷新页面也还在（标题右边会显示「草稿已保留」）。只有保存成功、或者你主动点「清空」，草稿才会清掉。如果草稿还没保存你就去查另一个词，它会先问你要不要放弃当前草稿。

**后到的网络结果不会覆盖你手改的内容**：你手动改过的字段（释义、例句等）会被锁定，慢一步返回的查询结果只补你没改的部分。

**如果这个词已经收录过**：页面会提示"这个单词已经收录"，并显示原来的释义和例句。这时保存不会覆盖旧内容，只会增加一条遇词记录、追加你这次新加的例句。想改旧释义，去「我的单词本」里改。

### 2. 我的单词本

左边是词表，可以搜索（英文或中文都行）、按来源筛选、按时间或字母排序。右边是选中词的详情：

- 改单词、音标、释义（点「编辑」）
- 例句：设为主要例句、编辑、删除、UK/US 朗读
- 遇词记录：看到这个词都遇到过几次、在哪遇到的
- 删除整个词（会二次确认，删了不能恢复）

例句的排版是：英文用正文色（深色主题下是浅色），中文用次级色但依然清晰可读；主要例句会稍微突出。深浅主题下都做过对比度检查，不会出现白底白字或深底深字。

### 3. 设置

- **外观**：跟随系统 / 浅色 / 深色（顶部右上角也能直接切）
- **发音**：默认口音、发音引擎（自动 / 只用词典音频 / 只用浏览器语音）。语速不在这里了，去发音按钮旁边的 `1×` 按钮切
- **语音检测**：列出这台电脑实际可用的英式、美式语音。如果某项是空的，说明系统没装对应语音包
- **本地数据文件**：显示真实保存路径、当前同步状态、打开数据文件夹、立即同步、历史备份列表、从电脑文件恢复（合并 / 替换）
- **备份**：导出 / 恢复 JSON（完整数据，推荐每周一次）
- **Excel**：导入现成的单词表、导出成 Excel、下载导入模板
- **数据管理**：查看数量统计、申请持久化存储、清空数据
- **AI 例句**（可选）：填入兼容 OpenAI 的接口地址和密钥后，记录页会出现「AI 生成参考例句」按钮

## 三、发音说明

单词发音按这个顺序尝试：

1. **词典音频**（在线，真人录音，英式 / 美式分开）
2. 词典音频失败 → **浏览器语音合成**（Web Speech API，用系统装的 en-GB / en-US 语音）

按钮排布是：`发音来源：词典英音　[英音] [美音] [1×]`。左边那行提示出现在固定区域，出现和消失都不会让按钮左右跳。

- 点一次播放一遍，不会循环。
- 两种方式都失败时会明确告诉你原因（比如"当前电脑没有安装英式（en-GB）语音"），不会静默无声。
- 例句朗读只能用浏览器语音合成（词典音频只有单词）。所以如果系统没装英语语音包，例句朗读会提示不可用。

**语速**：`1×` 按钮点一下变 `0.75×`，再点回来。记录页、单词本、例句朗读共用同一个设置，切页跟着走，下次打开还是你上次选的。慢速是真实变速：词典音频用播放速率（保持音高不变调），语音合成用 rate。

## 四、双重保存与找回数据（重要）

### 自动保存到哪儿

`C:\Users\<你的用户名>\Documents\WordLab\`

- `wordlab-data.json` —— 当前完整词库快照（每次改动都会更新）
- `wordlab-data.prev.json` —— 上一次成功写入的版本
- `backups\` —— 每天第一份快照，保留最近 10 天
- `logs\` —— 写入失败时记的原因

设置页「本地数据文件」里会显示这台电脑上的真实路径，还有「打开数据文件夹」按钮，不用自己去翻。

这个文件夹不在代码目录里，所以重装依赖、重新构建、升级版本都不会动它。

### 状态怎么看

| 状态 | 含义 |
| --- | --- |
| 已同步到电脑 | 浏览器和磁盘都是最新的 |
| 正在同步到电脑… | 刚刚有改动，正在写盘 |
| 同步失败 | 浏览器存好了，但磁盘没写成功，会自动重试，也可以在设置页手动「立即同步」 |
| 需要确认 | 浏览器词库是空的，而电脑上有完整词库，系统拒绝覆盖，需要你去设置页确认恢复 |

注意：磁盘写失败时只会说"同步失败"，不会骗你说"双重保存成功"。

### 数据丢了怎么找回

**浏览器数据被清空 / 换了浏览器 / 换了地址**：

1. 打开网站，顶部会出现提示条（电脑上有完整词库，但浏览器里是空的）
2. 进设置 → 本地数据文件 → 「从电脑文件恢复（合并）」
3. 二次确认后恢复，词库就回来了

**误删了某个词**：可以试试 `backups\` 里的每日快照，用「从电脑文件恢复」的**替换**模式（会先清空当前词库再整体还原，谨慎使用）。更稳的做法还是导出 JSON 备份。

**保险做法**：每周在设置页导出一次 JSON 完整备份，存到网盘或 U 盘。升级版本前也建议先导一次。

## 五、Excel 导入

1. 设置 → Excel → 选择文件（.xlsx / .xls / .csv）
2. 选工作表 → 确认表头在第几行
3. 把表里的列对应到「单词 / 音标 / 词性 / 中文释义 / 例句 / 例句翻译 / 来源」
4. 看预览：会告诉你识别出多少单词、多少例句、多少重复词、哪些字段没识别
5. 点导入。重复的词按"合并"处理：不覆盖已有释义，只补新例句和遇词记录

导出会生成多个工作表：单词、释义、例句、单词-例句关联、来源、遇词记录。分开存是为了不丢关系；想给人看的话看「单词总表」那一页。

## 六、数据来源

| 内容 | 来源 | 说明 |
| --- | --- | --- |
| 中文释义、词性、音标、词形变化 | ECDICT（开源，MIT） | 已抽取高考 / 中考 / 四级 / 六级 / 考研标签共 7422 词，打包在站内，离线可用 |
| 英式 / 美式音标、英文释义、英文例句 | Free Dictionary API | 免费公开接口，需要联网 |
| 例句中文翻译 | MyMemory 翻译接口 | 免费公开接口，机器翻译，仅供参考 |
| 单词发音 | 在线词典发音接口 + 浏览器语音 | 在线播放，不下载、不存储 |
| 例句朗读 | 浏览器 Web Speech API | 依赖系统语音包 |

断网时：本地词典仍然能查出中文释义和音标；英文释义、例句、翻译不可用，页面会标注哪些字段缺失，可以手动填。

## 七、注意事项

- **必须用 `启动WordLab.bat` 打开**。直接双击 `dist/index.html` 是打不开的（浏览器不允许本地文件加载模块脚本），而且那种方式没有本地文件同步。
- 本地文件写入接口只在本机回环地址（localhost / 127.0.0.1）提供，且只允许写 WordLab 数据文件夹里的文件，别的地方访问不到、也写不了。
- 数据文件里不含 API Key 等敏感信息，只有词库内容。
- 用无痕窗口、清理浏览器数据、换浏览器，都会让浏览器里的词库消失——但电脑上的 JSON 快照还在，可以恢复。
